The Kanade mascot and visual identity are original artwork created for the Kanade project. The mascot is Kanade's own original character and has no name.

They are not affiliated with or endorsed by any anime, game, character, studio, publisher, or other third-party franchise. Third-party use of the Kanade name and branding does not imply endorsement by the Kanade project.

| Asset | What it is |
| --- | --- |
| `assets/kanade-mascot.png` | The mascot |
| `assets/kanade-mark.png` | The mark |

Both files are copied from the repository by `npm run sync` and live in `src/assets/`. The site's favicon is a 192 px copy of the mark.
