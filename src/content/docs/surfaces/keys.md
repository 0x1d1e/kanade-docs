The Keys Surface is a cheatsheet you can search: niri's keybinds, read from `$NIRI_CONFIG` (else `niri/config.kdl` in niri's config directory) and the files it includes, then the keys Kanade's own Surfaces take. Typing searches, Up/Down, Tab, Home and End move the ring through the results.

There is nothing to configure. It is part of the `keys-surface` Module, which is on by default.

:::note
The keys each Surface takes are listed on [Keybinds](/getting-started/keybinds/). The Surface reads niri's config rather than asking niri, so it shows the binds the files hold.
:::
